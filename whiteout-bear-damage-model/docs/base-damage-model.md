# 打熊单回合基础伤害模型（阶段 2）

## 范围

当前模型只处理兵数、兵种、兵种等级常数、战报攻击和战报穿透，输出的是单回合伤害。不处理英雄、车身、概率技能、火晶技能、易伤、额外伤害、减防或优化，也不会在此乘以 10。

## 变量

- `N`：整支部队总兵数。
- `n`：当前兵种兵数。
- `k = 0.0075577`。
- `C_d`：兵种伤害系数，来自独立配置。
- `C_t`：兵种等级常数，来自独立配置。
- `A`：战报攻击百分数转换后的小数。
- `P`：战报穿透百分数转换后的小数。

战报输入保留百分数单位。例如输入 `444.35` 表示 `+444.35%`，进入公式前转换为：

```text
A = 444.35 / 100 = 4.4435
1 + A = 5.4435
```

穿透采用相同转换。

## 统一公式

```text
D = k × sqrt(min(N, 5000)) × sqrt(n) × C_d × C_t × (1 + P) × (1 + A)
```

第一个根号只由整支实际参战总兵数 `N` 决定：`N > 5000` 时使用
`sqrt(5000)`，`N < 5000` 时使用 `sqrt(N)`。第二个根号始终直接使用
当前兵种数 `n`，不截断，也不按 `n` 选择公式。

## 多兵种总伤害

总兵数由所有输入兵种的兵数相加得到：

```text
N = n_s + n_l + n_m
```

每个兵种使用同一个 `N`，以及自己的 `n`、`C_d`、`C_t`、`A` 和 `P` 分别计算：

```text
D_total = D_s + D_l + D_m
```

三个兵种共享同一个 `sqrt(min(N, 5000))`，再分别使用自己的 `sqrt(n)`。

## 精度与取整

- 所有中间步骤使用 JavaScript `number` 浮点计算。
- 计算层不调用 `floor`、`round` 或 `ceil`。
- `DamageResult` 保存未格式化的计算结果。
- 游戏内部的真实取整规则仍为待验证项。

## 5000 上限特征

`N=5000` 是第一个根号的连续上限点；超过该值后第一根号保持
`sqrt(5000)`。`n` 没有 5000 截断或跳变。
