# 活动日历管理重做验收说明

日期：2026-08-25

## 页面结构

- 页面依次显示活动分类、日程编辑器、日程预设和已配置日程。
- 日程结构只有“普通日程”和“组合日程”，“重复日程”是两者共用的选项。
- 原有单日、连续、重复、组合、甘特任务块、每日清单、复制、启停、删除功能均保留。

## 日期验收

1. 选择普通日程和“连续时段”。
2. 点击“今天”“明天”或“下周同一天”，开始日期应立即变化。
3. 修改“单次持续天数”，自动结束日期和下方预览应同步更新。
4. 切换到“多个不连续日期”，可按换行、逗号或空格输入多个日期；保存后再次编辑，日期不得被错误合并为连续区间。
5. 开启“重复日程”，可按天、周、月循环，并选择长期、截止日期或循环次数；持续多天的活动每次出现都保持相同持续天数。

## 颜色验收

1. 勾选“跟随分类颜色”，切换活动分类，取色器和色值同步为分类颜色。
2. 取消跟随后，点击任意暖色色块，取色器和十六进制色值同步。
3. 修改取色器或输入完整 `#RRGGBB` 色值，其他颜色控件同步。

## 组合日程验收

- 可选择甘特任务块或每日清单。
- 子任务支持覆盖整个日程、连续偏移、指定日期偏移、子任务循环。
- 子任务保留启用、重点标记、起止时间、颜色、说明和排序。
- 父组合日程可开启重复，并可设置单次持续多天。

## 预设验收

1. 填写任意日程，点击“保存为预设”并输入名称。
2. 刷新页面后预设仍存在，证明数据保存到服务器。
3. 点击“套用”，开始日期自动平移到今天，持续天数、不连续日期间距、循环规则和组合子任务保持不变。
4. 同名预设提示已存在；预设可删除。

## 兼容与部署

- 原有 `single`、`continuous`、`recurring`、`composite` 和 `date-list` 数据均可继续读取和编辑。
- 更新接口继续保留 POST 与 PATCH；页面使用 POST，避免部分 CDN 对 PATCH 请求解析失败。
- 预设使用现有 `site_settings` 表的 `calendar_schedule_presets` 键，无需新增数据库表或手工执行 SQL。
- 部署时需同时更新服务端 JavaScript、管理页 HTML、`admin-calendar-page.js` 和 `admin-calendar-page.css`，并重启 Node 服务。
