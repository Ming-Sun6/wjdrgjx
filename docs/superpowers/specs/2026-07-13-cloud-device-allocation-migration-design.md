# 云机分配工具迁移设计

## 目标

将 `C:\Users\34502\Desktop\云机分配系统` 中两个实际工具迁移到无尽冬日工具箱，使用户可以通过以下入口访问：

`https://wjgl.store/function/wjdeyj/fpgj/fpgj.html`

入口页提供两个可点击入口，分别进入 AI 云手机分配系统和最强冬日卡密分配工具。

## 范围

迁移以下两个不同的工具页面：

- `Ai云手机分配系统.html`
- `V2.6最强冬日卡密分配工具.html`

不迁移以下文件：

- `V2.6最强冬日卡密分配工具 - 副本.html`，因为它与原文件的 SHA-256 完全相同。
- `合并网站.html`，因为它仅通过 iframe 同时加载上述两个工具，不包含第三个独立工具。

## 文件结构与 URL

在 Express 已公开的 `public` 静态目录下新增：

```text
public/function/wjdeyj/fpgj/
|-- fpgj.html
|-- ai.html
`-- v2.6.html
```

对应公开地址：

- `fpgj.html`：两个工具的入口页。
- `ai.html`：AI 云手机分配系统。
- `v2.6.html`：最强冬日卡密分配工具。

工具页面采用 ASCII 文件名，避免中文 URL 在服务器、CDN 或分享场景中的编码差异。

## 页面行为

`fpgj.html` 显示两个明确的工具入口。点击入口后，在当前标签页通过相对链接进入对应工具页面。入口页不使用 iframe，也不在两个工具外增加运行时包装层。

迁移后的 `ai.html` 和 `v2.6.html` 保留源文件的页面结构、视觉样式、脚本和功能，不改变其 Excel 导入导出、浏览器端数据处理或其他现有行为。页面继续使用源文件已有的 Tailwind CSS、Font Awesome 和 SheetJS CDN 依赖。

## 数据与错误处理

两个工具均为浏览器端静态页面，不新增后端接口或服务端数据流。入口页只使用相对 URL，因此在正式域名与本地静态服务中具有相同行为。

若外部 CDN 不可用，工具页面原有的样式或 Excel 能力可能受影响；本次迁移不改变这一既有依赖，也不新增离线资源方案。

## 验证标准

- `fpgj.html`、`ai.html` 和 `v2.6.html` 均能通过项目静态服务返回 HTTP 200。
- `fpgj.html` 恰好提供两个工具入口，链接分别指向 `ai.html` 和 `v2.6.html`。
- 两个工具页面与对应源文件内容一致，仅文件名和所在目录发生变化。
- 两个工具页面仍包含原有 CDN 和 SheetJS 依赖。
- HTML 中的内联 JavaScript 能通过语法检查。
- 不包含重复副本或旧 iframe 合集页。
