# 历史移民分组后台配置设计

## 目标

新增后台“历史移民分组”配置页面，使管理员可以在不修改 HTML 的情况下：

- 新增、修改、停用历史移民日期；
- 按固定间隔生成后续移民日期；
- 修改历史分组计算规则；
- 对特殊日期和特殊区间进行单格手动覆盖；
- 让历史移民分组页和移民预测页随邻邦进度配置同步更新。

## 推荐架构

采用“规则计算 + 手动覆盖”的混合模式。

邻邦进度配置作为区间和阶段日期的基础数据；历史移民配置只保存移民日期、分组规则和必要的人工覆盖。公开页面在加载时读取统一配置，接口失败时继续使用原有静态数据。

```text
邻邦进度配置
        ↓
历史移民日期与规则
        ↓
历史移民分组页面
        ↓
移民预测页面
```

## 配置数据

保存到现有 `site_settings` 表，配置键为 `history_immigration_config`：

```js
{
  version: 1,
  intervalDays: 28,
  dates: [
    {
      date: "2026-08-17",
      enabled: true,
      note: "",
      overrides: {
        "417~522": "group-2"
      }
    }
  ],
  rules: {
    displayOffsetDays: 1,
    groupMode: "same-progress",
    mergeContinuousRanges: true,
    showStageDetails: true
  },
  updatedAt: null,
  updatedBy: null
}
```

### 字段规则

- `intervalDays` 限制为 1–90 天，默认 28 天；
- `dates` 按日期升序保存，禁止重复日期；
- 每期日期可启用或停用，停用日期不参与公开页面计算；
- `overrides` 的区间键必须来自邻邦进度配置；
- `groupMode` 初期支持 `same-progress`，表示按展示日加偏移后的邻邦阶段归组；
- `displayOffsetDays` 默认 1，保留现有“展示日 +1 日”口径；
- 无效覆盖、无效日期或未知规则保存时返回明确错误。

## 后台页面

新增菜单：`后台管理 → 历史移民分组`。

页面分为四个区域：

### 日期管理

- 默认间隔天数输入框；
- 新增日期；
- 按间隔生成下一期；
- 修改日期、备注和启用状态；
- 删除或停用日期；
- 按日期升序显示。

### 分组规则

- 展示日偏移天数；
- 分组模式；
- 是否合并连续区间；
- 是否显示阶段详情。

### 分组矩阵

- 行为邻邦区间；
- 列为历史移民日期；
- 单元格显示自动分组结果；
- 点击单元格可切换为手动覆盖；
- 手动覆盖显示标记和备注；
- 支持清除覆盖恢复自动计算。

### 预览与保存

保存前展示变更摘要，包括日期变化、规则变化和受影响的分组数量。保存成功后显示更新时间和操作人。

## 服务端接口

### 公开接口

```http
GET /api/history-immigration
```

返回标准化配置或默认配置。发生读取异常时返回静态默认配置，不能导致页面白屏。

### 管理接口

```http
GET  /api/admin/history-immigration
POST /api/admin/history-immigration
PUT  /api/admin/history-immigration
```

管理接口必须使用现有管理员鉴权、`getSetting`、`setSetting` 和 `auditAdminAction`。保存前统一标准化配置，保存后记录日期数量、规则和覆盖数量。

## 页面联动

### 历史移民分组页

移除对固定日期和固定区间的唯一依赖，优先读取：

1. 邻邦进度公开配置；
2. 历史移民公开配置；
3. 原有静态数据作为最终兜底。

根据配置重新计算每期分组；手动覆盖优先级高于自动结果。

### 移民预测页

与历史移民分组页复用同一套配置和分组计算函数。预测日期继续基于历史移民日期序列外推；当邻邦进度、日期或规则变化时，矩阵、当前区服分组和后续预测同步重算。

## 兼容和回退

- 未配置时保持当前页面展示结果不变；
- 配置接口失败时继续使用页面内嵌默认数据；
- 新阶段名称或区间变化不会破坏旧配置；
- 未知阶段显示为“暂无数据”，不抛出前端异常；
- 保存失败不覆盖上一次有效配置。

## 测试范围

- 日期排序、重复日期和间隔生成；
- 规则标准化和非法值拒绝；
- 手动覆盖优先于自动分组；
- 邻邦进度修改后历史分组结果变化；
- 历史日期修改后移民预测日期和矩阵变化；
- API 异常时公开页面静态兜底；
- 管理接口鉴权和审计日志；
- 后台新增日期、修改日期、清除覆盖和保存流程。
