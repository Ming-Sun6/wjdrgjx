# 日历页面移动端 CSS 删除设计

## 目标

删除活动日历页面专用样式中的全部移动端媒体查询，使页面只保留统一的桌面布局与基础横向滚动行为。

## 修改范围

- 删除 `public/function/calendar-gantt.css` 中全部 `@media (max-width:760px)` 规则。
- 保留基础桌面样式、时间轴样式、横向滚动和 `?embed=1` 首页预览模式。
- 保留 HTML 中的手机横屏提示；该提示属于内容，不是移动端布局代码。
- 更新 `tests/calendar-gantt-ui.test.js`，移除对旧移动端布局的断言，并新增“日历样式不包含移动端媒体查询”的约束。

## 不在本次范围内

- 不修复默认时间轴只显示一周的问题。
- 不整理重复或互相覆盖的非媒体查询 CSS。
- 不修改日历 API、后台管理或数据模型。
- 不删除首页 iframe 嵌入预览功能。

## 验证

1. 先增加禁止 `max-width:760px` 媒体查询的测试，并确认它在现有 CSS 上失败。
2. 删除移动端媒体查询后重新运行日历 UI 测试。
3. 运行日历领域与路由测试，确认纯样式删除未影响日期和接口逻辑。
4. 检查最终差异，确认没有误删基础桌面样式或嵌入模式样式。
