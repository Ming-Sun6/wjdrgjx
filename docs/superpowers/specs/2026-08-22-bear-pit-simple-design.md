# 熊坑排布简约版接入设计

## 目标

将 `C:\Users\34502\Desktop\wjdr-bear-pit-designer-main` 整理为当前工具箱中的独立静态工具页，首页新增入口，名称为“熊坑排布简约版”。

## 方案

- 使用源项目的生产构建产物作为静态页面资源，避免把 Vite 开发依赖和缓存搬入主项目。
- 将运行所需的 HTML、JavaScript、CSS、图片和字体资源放到 `public/function/bear-pit-simple/`，通过独立入口页访问。
- 首页工具目录新增唯一工具 ID 和入口链接，沿用现有工具可见性、徽章和主题管理逻辑。
- 工具页保留源项目完整的排布、拖拽、保存和导出交互，并增加返回工具箱入口；不改动核心算法和数据。

## 兼容与验证

- 静态资源全部使用工具页相对路径，适配主站部署前缀。
- 不复制 `node_modules`、`.git`、构建缓存和开发配置。
- 增加测试确认首页入口、工具页面和主要资源存在，并运行全量测试。
