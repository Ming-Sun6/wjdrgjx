# 移民预测周一日期规则

## 目标

未来移民预测日期直接表示实际开放日，并且每一期必须是周一。页面展示、倒计时和分组进度计算使用同一个周一日期，避免额外加一天后产生口径偏差。

## 规则

- 保留历史日期数据，继续用于估算最近移民周期。
- 计算最近六个历史间隔的中位数后，将周期校准为最接近的完整周数，且最少为两周。
- 最后一个历史展示日先按原有 `+1 日` 口径得到历史有效日期，再校准到该日期当天或之后最近的周一，作为历史锚点；首期预测必须在此锚点基础上再增加一个完整周期。
- 日期换算拆成两条明确路径：历史展示日继续使用 `+1 日` 的历史有效日期；预测开放日直接使用页面显示日期，不再额外偏移。
- 预测矩阵、分组进度、倒计时和默认期选择全部使用预测开放日路径；历史矩阵和历史对照继续使用历史有效日期路径。
- 页面文案明确区分“历史展示日”和“预测开放日”。

## 验证

- 自动测试确认所有预测日期均为周一。
- 自动测试确认当前 29 天中位数被校准为 28 天。
- 自动测试确认预测日期作为开放日参与默认期选择，不再额外偏移一天。
- 自动测试确认预测矩阵和进度计算使用周一开放日，不会落到周二。
- 回归测试确认历史展示日仍然执行 `+1 日`。
- 边界测试确认历史有效日期本身为周一时不会多跳一周，但首期预测仍会增加一个完整周期。
- 运行完整测试集并检查代码差异。
