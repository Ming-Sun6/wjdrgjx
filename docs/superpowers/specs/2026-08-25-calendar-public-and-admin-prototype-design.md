# 活动日历公开页修复与管理端原型设计

日期：2026-08-25

## 范围

本次分为两个互不混淆的交付：

1. 修改公开活动日历及其首页嵌入入口。
2. 新建一个独立的活动日历管理 HTML 原型供验收，不替换、不引用、不接入现有管理端活动日历页面，也不调用真实管理接口。

## 公开活动日历

### 首页入口

- 首页“全部”分栏不显示活动日历内容。
- 只有用户点击“活动日历”分栏时，才创建并加载日历 iframe。
- 用户从“活动日历”切换到其他分栏时移除 iframe；再次进入活动日历时重新创建，确保“全部”既不展示也不继续承载日历资源。
- 嵌入区域明确显示“当前为活动日历预览”。
- 嵌入区域提供“打开完整日历”按钮，打开 `/function/calendar.html`。

### 主题按钮

- 活动日历页阻止公共主题脚本创建或在创建后立即移除 `#themeToggleBtn.wjdr-theme-fab`，最终 DOM 中不得存在该节点，也不得保留可聚焦的替代节点。
- 只限制活动日历页，不改变其他工具页的主题切换行为。
- 日历继续使用现有淡暖色视觉，不新增替代主题按钮。

### 横屏与竖屏查看

- 完整日历工具栏新增“竖屏查看”和“横屏查看”按钮。
- 用户选择使用 `sessionStorage` 的 `wjdr.calendar.viewMode` 保存；默认根据当前视口方向选择 `portrait` 或 `landscape`，存储不可用时退回页面内存状态。刷新、切换周/月、上一段/下一段时不重置。
- 竖屏查看使用紧凑七列：七天必须在视口内完整显示，不横向滚动；分类名称允许缩写，日期显示紧凑格式，活动块最多显示两行，点击查看完整详情。
- 横屏查看使用舒展七列：显示更完整的分类、日期和活动名称，仍不需要左右滚动。
- 手机上点击横屏查看时先立即切换横屏布局，再请求全屏；只在 `fullscreenchange` 确认进入全屏后调用 Screen Orientation API 的 `lock('landscape')`。全屏或方向锁定不支持、失败或被拒绝时，保留横屏布局并提示用户旋转设备。
- 切换回竖屏时退出方向锁定；不能强制解除系统方向时不得报错。
- 页面只退出由本页主动进入的全屏；监听用户退出全屏并安全解除方向锁定，不自动改变已选择的布局。设备实际旋转只更新辅助提示，不覆盖手动选择。
- 电脑端保留两个查看按钮，作为布局预览控制，不请求全屏或方向锁定。
- 周视图在 320px、360px、390px 及以上宽度均须让星期一至星期日横向完整可见；月视图同样固定七列，按周纵向排列，不横向滚动。竖屏可使用最小字体、两行截断和紧凑分类标签，横屏增加列间距与可见文字，但都不得设置超过视口的日历最小宽度。

### 嵌入预览

- `?embed=1` 模式显示轻量预览提示栏，不显示完整页固定标题栏。
- 预览可以保留当前周日程，但不承担完整操作说明。
- 在 320px、360px、390px 手机宽度下，预览容器和提示栏不得横向溢出；按钮保持完整可见且触控高度不小于 40px。
- “打开完整日历”在 iframe 内优先通过同标签页 `window.top.location.href='/function/calendar.html'` 打开，避免继续嵌套；若顶层访问被浏览器阻止，则退回 `window.location.href` 在当前 frame 打开。

## 管理端独立 HTML 原型

### 交付边界

- 新建独立静态 HTML，建议路径：`docs/prototypes/calendar-admin-v2.html`。
- 原型可直接双击打开，使用模拟分类、日程和预设数据。
- 页面显著标注“验收原型，未接入生产管理端”。
- 不修改现有管理端 HTML、管理脚本、服务端路由或数据库。
- 用户验收通过前，不执行接入工作。
- 原型为 `file://` 可运行的单文件，HTML、CSS、JavaScript 和模拟数据全部内联；不得使用 `fetch`、XHR、WebSocket、表单 `action`、外部 URL、现有管理端脚本/样式或真实管理接口路径。

### 页面结构

- 左侧为步骤导航：基本信息、日期与重复、组合任务、颜色与说明、预设。
- 右侧为当前步骤的大编辑区，字段分组和帮助文字清晰。
- 顶部显示当前编辑状态与“新建日程”。
- 底部固定显示主要动作：保存草稿、保存为预设、完成日程。
- 页面下部或独立抽屉展示预设库与已配置日程。

### 原型交互

- 可切换普通日程/组合日程。
- 可切换连续日期/不连续日期以及开启重复。
- 可调整持续天数并看到结束日期预览。
- 可选择分类联动颜色、暖色色板或输入色值。
- 可添加模拟组合子任务。
- 可切换步骤、套用模拟预设和查看模拟日程，不执行网络请求。
- 桌面端重点展示左侧步骤导航；手机端自动改为顶部横向步骤标签。

## 错误处理与兼容

- 全屏、方向锁定和退出锁定均以能力检测和 `catch` 保护，失败只显示提示，不阻断日历。
- 保留周视图、月视图、日期选择、详情弹窗和最近 18 个月范围控制。
- 公开 API 和现有日程数据结构不变。
- 首页仍保持点击活动日历后才加载资源。

- 自动测试确认活动日历最终 DOM 中不存在自动注入的悬浮主题按钮，并确认其他工具页逻辑不变。
- 自动测试确认 `sessionStorage` 偏好、全屏后方向锁定时序、失败降级和退出清理。
- 静态扫描确认管理端原型不含网络 API、外部资源、管理端资源路径或表单提交，并保留“未接入”标识；通过 `file://` 手工打开验收交互。
- 变更边界检查：除公开日历相关文件、对应测试、规格文档和 `docs/prototypes/calendar-admin-v2.html` 外，不修改现有管理端 HTML、管理脚本、路由、数据库迁移或接口代码。
- JavaScript 语法检查、日历专项测试和相关首页回归必须通过。
