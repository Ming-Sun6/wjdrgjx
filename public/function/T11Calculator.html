根据当前研究等级与目标等级，实时计算加速时间、火晶颗粒和五类资源消耗。 页面采用卡片式结果重构，手机和电脑都不再依赖横向大表格。

数据来源

计算规则
按“已研究等级 < 等级 <= 目标等级”累计加速、颗粒和资源。

研究速度

折算后天数 = 原始天数 / (1 + 研究速度 / 100)

预设方案

先用预设，再按需手动微调每个科技的起止等级。

科技设置

每项科技都是独立设置卡，直接调整已研究等级和目标等级。
